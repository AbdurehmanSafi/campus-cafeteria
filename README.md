# Campus Bites - Campus Cafeteria Information Website

A small static website for the Campus Bites cafeteria, built collaboratively
with Git and GitHub for DevOps Fundamentals (SEST4663), Assignment 01.

## Pages
- Home (index.html)
- Menu (menu.html)
- Deals (deals.html)
- How to Order (order.html)
- Feedback & Contact (feedback.html)

## Workflow
- `main`: production-ready code
- `develop`: active development
- `feature/<page-name>`: one branch per page
- `release/v1.0`: QA before production
